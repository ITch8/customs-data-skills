# 芯片供应商与真伪风险核验

把“供应商看起来可信”拆为可查证的公司身份、渠道关系、具体批次证据和交易控制。公开网页、证书图片或 AI 识图不能证明待交付实物为原装正品。

## 输入

尽量取得法定公司名、注册地、官网/企业域名邮箱、销售主体与收款主体、联系人、目标制造商和 MPN、数量、报价、库存所在地、批次/日期码、包装标签照片、可提供的追溯/质量文件、拟用付款和交付条件。敏感凭证和完整银行信息不要贴入对话。

## 核验步骤

1. **主体一致性**：从企业登记或监管机构等官方公开来源核对公司法定名称、地址、经营状态；对照合同、发票、网站、邮箱域名和收款主体。异名或个人账户要取得可验证的书面解释并升级审核。
2. **渠道路径**：从芯片制造商官网进入授权经销商/销售渠道查询，记录目标国家/地区、授权范围、页面 URL 和查询日期。搜索引擎结果、平台会员、旧授权书和供应商自述不能替代原厂当前查询。官方名单没有该公司时，只能记录“未核实为授权渠道”，不能断言其违法或售假。
3. **具体货物**：让卖方逐批提供库存所在地、数量、批次/日期码、原厂标签/封装照片、上游来源、原始采购凭证（可脱敏）、CoC/合格证明、测试和保修政策。核对所有文件里的主体、料号、批次、数量和签发日期是否相互一致。
4. **抽样和验货**：对高风险或高价值交易约定独立抽样、外观/电性/必要的失效分析或第三方实验室检查、封样和不合格处置。测试方案及接受标准由买方质量/工程人员确定；外观无异常不等于鉴真。
5. **交易控制**：核对合同主体、收款账户变更、预付款比例、交期、交付条款、质量责任、退换窗口、短装处理和争议解决。首次交易可先完成资质审核、样品/小批验证与合同审阅，不把“先款后货”本身当成唯一风险判断。

## 证据来源和新鲜度

使用 `web_search` 查询官方企业登记、制造商渠道查询页和相关认证/监管发证机构；对易变授权状态写查询日期。供应商提交文件记录原件/副本、签发方和适用批次。内部知识库可查本企业的合格供应商规则、历史异常和客户质量要求，先确认资料的生效范围与复核日期。

## 输出

按“核实事实 / 供应商声明 / 未独立核实 / 风险与证据 / 建议补件 / 人工决策”分栏。对每项公开事实附 URL 和查询日期。不能只给一个总分；缺少关键文件、主体/账户不一致或批次无法追溯时建议暂停付款/下单并说明补证路径。不要声称已经鉴定真伪、授权或交易安全。
