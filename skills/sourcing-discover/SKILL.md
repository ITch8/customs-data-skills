# 供应商寻源与初筛

把"我要找这类工厂"变成一份**可回溯、可核对**的候选清单，并把判断权交回给人。

本技能负责的是**发现与初筛**。选定候选后的主体核验、渠道真伪、批次追溯走依赖技能
`chip-supplier-check`（芯片品类）或人工尽调。不要用本技能代替核验。

## 0. 开始前先自述数据源能力

先调用 `sourcing_capability`。若没有任何数据源 configured，**直接告知用户需要先配置
检索服务或 1688 开放平台凭证，然后停止**。

绝不在未检索的情况下编造供应商名单。空列表与"尚未检索"是完全不同的两件事：
前者是市场结论，后者是工具故障。把后者说成前者，会让用户误判整个品类是否存在供应商。

## 1. 把需求写成检索条件

向用户确认或推断以下项，逐项标记「已确认」与「待确认」，**禁止默默补齐**：

- 品类与关键词（中英文都要给，平台检索对英文更敏感）
- HS 编码：**必须是已确认的编码**，不接受产品名猜测
- 目标国家 / 地区
- 关键规格与认证要求（如 CE、UL、ISO、SMETA）
- 数量、MOQ 预期、交期、目标价带
- 品类方向：`general`（通用商品）或 `chip`（电子元器件）

若用户只给了一个模糊品类名（如"减速器"），**先问清楚是谐波/行星/RV 还是摆线**，
再检索。品类不唯一时，检索结果只能证明"这个关键词下的供应商"，不能证明符合所需规格。

## 2. 检索

调用 `sourcing_search`，可同时指定 `providers`（`web` 与 `alibaba_1688` 可组合）。

- 数据源失败时**如实回报**，不要用另一个数据源的结果冒充本次检索全貌。
- 1688 平台返回的起订量、阶梯价、30 天成交、诚信通年限都是**商家自填**信息，
  只能作为商业活跃度参考，**不构成对工厂身份的核实**。

检索完成后用 `sourcing_list_candidates` 取回候选的完整证据与卡口原因。

## 3. 逐条标注证据等级

系统已给出四档，**不要改写或自行升级**：

| 档位 | 含义 | 可用于 |
|---|---|---|
| `verified_fact` | 有官方/权威来源可回溯 | 可进入核验 |
| `supplier_claim` | 供应商自述（官网/平台） | 仅初筛参考 |
| `unverified` | 仅聚合站/单点信息 | 不得进入交易 |
| `conflicting` | 来源互相矛盾 | **阻断**，需人工先解决 |

每条候选必须附：来源链接、查询日期、证据理由。**没有 URL 的判断写成假设**，
单独列在"假设"一节，不要混进结论。

## 4. 三条不可绕过的约束

这三条与既有核验技能同源，不是新规矩：

1. **不编造供应商。** 没检索到的公司不许出现在清单里，即使"业内知名"。
2. **无证据的维度留空，不填 0。** `null` 表示"没查"，`0` 表示"查了确实为零"。
   把没查写成 0，等于用假数据把本该继续核验的候选提前淘汰。
3. **不宣称已核实。** 检索与初筛只是筛选，不等于尽调通过，更不等于可以下单。

## 5. 二次线索的天花板

展会名录、协会会员、黄页目录、LinkedIn 属于**二次线索**：它们能证明公司存在，
**不能证明它做这个品类、不能证明产能、不能证明合规**。

因此这类候选**一律不得单独支撑"可询价"结论**，必须再补一条独立来源
（官网产品页、原厂授权页、认证机构名录）才可升级。行业目录与协会名单天然是二次线索，
不要因为"看起来权威"就当一手证据。

## 6. 判断交给人：贸易商 vs 工厂

本技能**不判断**候选是工厂还是贸易商，也不替你下结论说"这家是源头工厂"。

原因是这类信号本质上无法证明：1688 上大量店铺是贸易商；工厂也可能只做 OEM；
注册资本、员工人数、场地照片都可以伪造。系统能提供的是客观信号（经营年限、
成交笔数、MOQ、是否有独立官网、认证情况），**"是不是真工厂"必须由人工判断**，
必要时索取厂房照片、产线视频、生产资质或实地验厂。

## 7. 输出格式

固定结构，便于人工逐条核对：

- **检索条件**：品类、关键词、HS、目标国家、数据源与查询日期
- **候选清单**：公司名 / 域名 / 国家 / 档位 / 来源链接 / 查询日期 / 商业信号
- **分级理由**：每条为什么是这一档（用系统给的理由，不要自创）
- **阻断项**：有 `promotion_blockers` 的候选，列出具体原因，**未经解决不得推进**
- **假设**：没有 URL 支撑的推断，全部集中在这里
- **下一步**：补什么证据、哪些可以发询价、哪些建议放弃
- **明确不回答**：谁是工厂、是否正品、是否可以付款

## 暂停条件

遇到下列情况，明确建议暂停并说明需要补什么，不要继续推进：

- 未配置任何检索数据源（先配置，不要用猜测填空）
- 候选全部只有二次线索证据，无法升级
- 存在 `conflicting` 档位候选（主体或账户不一致，必须先解决）
- HS 编码未确认
- 用户要求"直接给几家可靠的"而证据只够给"可初筛的"
