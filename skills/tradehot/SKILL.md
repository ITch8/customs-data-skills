# 外贸情报简报

把分散信息整理成中文业务简报。方法来自 [tradehot](https://github.com/chnjames/tradehot-skill)。检索只用 `web_search`。本环境没有原仓库的 `scripts/generate_report.py`、飞书技能或定时推送，不要调用它们，也不要假装已经推送。

每次输出都要回答：这件事是什么、影响谁、影响哪些市场或品类、机会、风险、今天可以做什么。

## 何时使用

用户要外贸或跨境日报、周报、平台政策、国家市场、HS Code、关税准入、物流、汇率、展会日历、竞争国或选品机会时使用。

## 报告类型

按用户意图选一种，不要一次做完全部：

| 类型 | 何时 |
| --- | --- |
| 日报 | 今天或最近的外贸热点 |
| 周报 | 最近一周 |
| 平台动态 | Amazon、TikTok Shop、Shopee、Lazada、Temu、SHEIN、AliExpress、eBay、Walmart、Etsy、Shopify |
| 市场简报 | 某个国家或地区 |
| HS / 品类 | 某个编码或品类 |
| 风险雷达 | 制裁、贸易救济、物流、支付 |
| 选品机会 | 适合开发的方向 |
| 关税准入 | 某品类出口到某市场的税和认证 |
| 外贸日历 | 展会、大促、备货窗口 |

## 检索

每条重要结论都要用 `web_search` 找来源。优先顺序：

1. 官方：海关、商务、税务、WTO、UN Comtrade、ITC、目标国政府、平台卖家中心公告。
2. 行业媒体。
3. 第三方数据。
4. 社媒和论坛只作线索，必须标明不确定，不能当事实。

关税、贸易救济、制裁、出口管制、认证、召回、税务和平台处罚，必须提示用户以官方文件或专业顾问为准，并提醒核对 HS 6/8/10 位、原产地和目标国税则版本。展会和大促日期标成规划参考，以主办方公告为准。

搜不到权威来源时写「未找到足够权威来源」，不要用静态印象填数字。

## 每条情报

- 类型：政策、平台、数据、物流、关税、合规、选品、风险、宏观。
- 影响对象：工厂、贸易公司、跨境卖家、独立站、平台卖家、海外仓、物流商。
- 影响市场和品类。
- 热度 0–25：时效、权威、业务影响、可操作性、风险程度各 0–5。
- 风险：低、中、高。
- 今天或本周可执行的动作。

排序：官方政策、平台规则、关税、物流或支付风险、市场数据、普通新闻。

没有 URL 的判断写成假设。报告用中文，公司名和术语可保留英文。需要交给用户保存时，写入文件并调用 `present_artifacts`。
