# 海关数据工具速查

使用前先判断需要 **A 企业级提单**、**B 宏观统计**，还是 **C 关税**。三类不可混用。免费范围会变；以网站当前提示为准。

## 先分清：统计 ≠ 买家名单

| 类型 | 代表工具 | 能回答 | 不能回答 |
|---|---|---|---|
| **B 统计** | UN Comtrade、中国海关统计、Eurostat、USITC DataWeb、CIMT | 哪国在买、规模、增长、中国份额 | **任何公司名 / 邮箱** |
| **A 提单** | ImportYeti、ImportInfo、付费提单库导出 | 哪家公司出现在公开/付费提单上 | 全球覆盖；隐私遮蔽后的真实买家 |
| **二次线索** | 展会名录、协会、LinkedIn、新闻 | 非公开提单国家的可跟进公司池 | 「海关提单已证实」——除非另有 A 证据 |
| **C 关税** | WTO TTD、目的国税则 | 进去还有没有税后竞争力 | 联系人 |

**实操默认：** Comtrade 做选市 → 美国用 ImportYeti（或付费导出）抓买家 → 欧洲/多数非公开提单市场用二次线索或付费库 CSV，交叉验证。

## A. 提单 / 采购商级

### 1. ImportYeti（美国海运提单）

- URL: https://www.importyeti.com/
- 免费：核心网页查询通常可免费使用（额度/反爬会变）
- 用途：反查同行**美国**客户；背调美国买家持续进口与供应商结构
- **覆盖：几乎仅美国（US Import / Manifest）海运**；对欧洲、东南亚、中东、拉美等作用极有限——勿当全球库
- 局限：无记录 ≠ 无进口；`To Order` / 银行 / AMS 隐私遮蔽常见；货代与清关行假阳性
- 操作：搜竞争对手英文名 → 看进口商、最近出货、累计次数、港口、产品描述、月度变化
- 信号：连续 2 年+向同行采购 = 稳定进口商；近月减量或增新供应商 = 供应链调整机会
- 反爬：遇登录墙 / Cloudflare → 请用户手动导出 CSV/Excel，交给 Skill 清洗评分（见 SOP Step 4c）
- 行动：近 12 个月重复采购 ≥2 次的美国买家优先；过滤 To Order / Broker

### 2. ImportInfo（美国提单交叉验证）

- URL: https://www.importinfo.com/
- 免费：部分摘要免费；完整/无限常需注册或订阅——勿当完全免费库
- 用途：验证 ImportYeti 结果（地址、名称变体、新提单、关联公司、产品匹配）
- 为何交叉：同一公司可能用总部/子公司/品牌/仓库/第三方代理名进口
- 行动：从现有美国名单抽 10 家双平台核验，剔除长期无采购记录者；同样支持用户导出交接

### 3. 付费海关 / 提单平台（用户自有账号）

- 不绑定具体品牌；用户已有订阅即可
- 用途：覆盖 ImportYeti 够不到的市场；批量导出；部分含隐私字段的合规使用范围以合同为准
- 行动：导出 CSV/Excel → 丢给 Agent → SOP 从清洗 / 过滤 / 评分 / 草稿接续  
- 报告标注：`source=user_export`

### 4. UK Trade Info 等官方入口（勿当「欧洲版 ImportYeti」）

- URL: https://www.uktradeinfo.com/ （及 Find UK Traders 等子工具）
- 免费：官方站点通常可访问
- **真相：** 英国及多数欧盟国家受 GDPR 等隐私规则约束，**官方早已不再公开美式「逐票 Consignee 提单」**。不要期望在英国官方库里稳定查到「某公司何时进了几柜」级记录。
- 用途：宏观/贸易统计辅助、有限的企业名录线索（若页面仍提供）——一律标 `secondary_lead` 或统计用途，**不得写成 BOL 证实买家**
- 欧洲买家池优先：展会展商名录、行业协会、公开新闻、LinkedIn、付费库导出
- 局限：不直接给采购邮箱；覆盖与字段以官网为准，变化频繁

## B. 国家贸易统计（无公司名）

### 5. 中国海关统计查询平台

- URL: https://online.customs.gov.cn/
- 免费：免费
- 用途：中国出口流向、国别金额/数量、同比环比、省市竞争——**无海外采购商名单**
- 步骤：确认编码 → 出口 → 月/年 → 按贸易伙伴排序 → 金额+数量 → 对比近 2–3 年
- 误区：进口额高 ≠ 中国供应商机会大；还要看中国份额、关税、产地偏好、价格上涨假象

### 6. UN Comtrade

- URL: https://comtradeplus.un.org/
- 免费：核心查询免费；批量/高级接口可能有账户限制
- **绝对没有买家/卖家公司名称**——只能做市场分层 / 规模分析
- 推荐条件：Reporter=进口国，Partner=China/World，Flow=Import，Commodity=HS，Period=近 3–5 年
- 三指标：总进口额、从中国进口额、中国占比（中国额÷全球额）
- 中国占比极低可能：关税壁垒、认证、产地偏好、未充分开发、**或编码错误**
- 避坑：优先完整年度，勿仅凭单月下结论；**禁止从 Comtrade「推」出公司名单**

### 7. USITC DataWeb（美国官方统计 + 关税）

- URL: https://dataweb.usitc.gov/
- 免费：公开访问；部分功能需 Login.gov 免费登录
- 与 ImportYeti：DataWeb = 市场总量；ImportYeti = 哪家公司在进口——需搭配
- 步骤：Imports for Consumption → HTS → 中国/全部 → 月/年 → 金额数量 → 供应国份额
- 信号：美进口增长但中国份额下降 → 转产地/关税/多元化；需重提效率、定制或成本优势

### 8. Eurostat Comext（欧盟货物贸易）

- URL: https://ec.europa.eu/eurostat/web/international-trade-in-goods/database
- 免费：免费
- 用途：把「开发欧洲」拆成具体国家：规模、增长、中国份额、可能分拨国——**仍无企业提单**
- 避坑：荷兰、比利时等港口/转口国，进口目的地未必等于最终销售地
- 行动：选 5 国分别算规模、增长、中国占比；企业级线索走二次渠道或付费导出

### 9. 加拿大 CIMT

- URL: https://www150.statcan.gc.ca/n1/pub/71-607-x/71-607-x2021004-eng.htm
- 免费：免费
- 用途：加进口总额、供应国、省份、金额/数量、月度；HS6 + 更细编码——宏观
- 场景：公司数量远少于美国时，先确认市场本身体量，勿用美国客户数量标准要求加拿大
- 避坑：金额÷数量 = 粗略统计单价，≠ 客户采购价

## C. 关税与准入

### 10. WTO Tariff & Trade Data

- URL: https://ttd.wto.org/en
- 免费：免费
- 查：MFN Applied、Bound、编码税率、部分进口统计与调整记录
- 为何必查：量大但高税/反倾销/保障/配额/认证/原产地 → 「客户多但价格永远谈不下来」
- 避坑：前期判断用；具体订单以目的国最新税则与专业报关意见为准
- 行动：进口规模与实际关税同表，重算到岸竞争力

## 工具选型速记

| 你想回答的问题 | 优先工具 |
|---|---|
| 美国哪家公司在买？同行客户是谁？ | ImportYeti → ImportInfo；或用户 CSV |
| 英国/欧盟谁在买？（公开逐票提单） | **通常没有** → 展会/名录/新闻/付费库导出 |
| 中国货主要去哪些国家？ | 中国海关统计 |
| 多国容量与中国份额对比？ | UN Comtrade（宏观 only） |
| 美国月度与供应国格局？ | USITC DataWeb |
| 欧洲先做哪国？ | Eurostat Comext |
| 加拿大值不值得投入？ | CIMT（对比美国） |
| 进去还有没有税后竞争力？ | WTO TTD |
| Agent 被反爬卡住？ | 用户导出 CSV/Excel → Skill 接续 |
